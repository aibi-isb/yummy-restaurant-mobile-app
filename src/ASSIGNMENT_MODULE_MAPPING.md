# YUMMY Assignment Module Mapping

- Software Engineering: reusable cards, hooks, services, route guards, and feature-scoped admin components keep the app maintainable.
- Database I & II: local/Supabase-ready services model users, foods, carts, orders, payments, and notifications with clear relationships.
- Data Communication and Networking: Supabase Auth/profile lookups use structured request/response flows from the mobile client.
- Distributed Computing: Expo app, Supabase, local storage, and notification records act as separate cooperating components.
- Operating Systems: AsyncStorage supports local persistence and mobile-friendly resource use.
- Data Mining: foods, orders, ratings, and order counts are structured for future popular-meal and recommendation features.
- Computer Graphics: existing Figma-based typography, spacing, cards, badges, and visual hierarchy are preserved.
- E-Commerce: cart, checkout, order creation, dummy payment, payment verification, and status tracking form the transaction flow.
- Web Technology: Expo Router, React Native components, JSON-style services, and Supabase authentication power the app.
- Entrepreneurship: menu CRUD, ordering, payment review, customer tracking, and dashboard metrics support restaurant operations.
- Ethics: validation avoids bad inputs, payment stores only dummy metadata/last four digits, and errors are shown transparently.
